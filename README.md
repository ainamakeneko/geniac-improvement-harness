# GENIAC Improvement Harness

A human-approved, evidence-driven loop for discovering and testing small operational improvements in resource-constrained welfare organizations.

The system is not optimized to produce apps. It is optimized to reduce real operational burden safely, using the smallest reversible intervention that can be tested.

Core loop:

Observation -> Opportunity discovery -> Human selection/approval -> Small experiment -> Evidence -> Evaluation -> Harness proposal -> Human approval -> Harness update

## Principles

- Separate observed facts, hypotheses, and unknowns.
- Do not invent facility-specific facts.
- Prefer reversible, low-cost experiments over large systems.
- A process change, spreadsheet, checklist, physical device, script, document, or no-build recommendation may be better than an app.
- Protect privacy, safety, dignity, and continuity of care.
- Human approval is required before field experiments and before permanent harness changes.
- Measure outcomes in the real workflow; software tests alone do not prove operational improvement.
